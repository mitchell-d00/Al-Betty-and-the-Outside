# Worked example from Combined MPLPB

**Combined MPLPB is the existing-repository, Al-first example.** It already had a local document reader, tests, instructions, and evidence for Al to inspect. Al uses that existing state to draft a repository-specific assignment for Betty. Mitchell authorizes and relays the scope. Betty freezes and tests the change, Mitchell relays the evidence, Al reviews it, and Mitchell decides what proceeds. The reader’s job makes the experimental distinctions visible. Discovering a passage, admitting a supported claim, and completing an entire answer are separate observations.

To build a new experiment, start with one observed miss or one disputed claim. Name the smallest behavior change. Freeze a positive, a close contrast that should withhold, and the valid behavior that must survive. Run a baseline, retain the raw outcome, then score the candidate with the same rule. Use a fresh packet for transfer and arrange independent preparation or scoring before making claims about independence. [Experiment plan](../templates/EXPERIMENT.md)
