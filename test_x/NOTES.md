# Test X participant notes

Each run gets a unique word-and-suffix identifier and an append-only note link.
Keep failed and aborted runs here too. No participant runs have been recorded at
initial implementation. Software verification uses temporary simulated responses
and does not count as an AI participant result.

| Run identifier | Revision and note | Submission / role | Score and scorer | Exposure |
| --- | --- | --- | --- | --- |

Copy a completed run directory to `runs/<identifier>/` only with permission to
publish its content. Add a row; preserve previous rows. An unreadable, unstarted
or unpublished run is never silently converted into a passed or published one.
